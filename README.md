## Чем занимаюсь

Веду финансово-экономический блок строительной компании: бюджетирование, план-факт по подразделениям (ЦФО), управление денежным потоком. Со временем рутинные операции — сводные таблицы из выгрузок 1С и банка, перекладка данных между Excel-файлами, сверки «копейка в копейку» — перевёл в **агентные конвейеры**: ИИ-агент по описанным правилам собирает готовые артефакты, а каждое число проходит независимый контроль.

**Ключевой принцип:** не «отчёт на глаз», а конвейер с самопроверкой — расхождение контрольных сумм либо ровно 0, либо сразу видно, где искать.

## 🛠 Стек

**Данные и автоматизация:** JavaScript/Node.js (SheetJS, pdf-parse) · Excel через COM-скриптинг (JScript/WSF) · OOXML-перепаковка · Git
**Отчётность:** Excel с живыми формулами и группировками · HTML/SVG-дашборды · Markdown-отчёты с контрольными суммами
**Агенты:** Claude Code — скиллы, хуки, конвейеры «данные → артефакт → независимая проверка»
**1С:** выгрузки (ОСВ, журналы проводок, ведомости, платёжные реестры) как первичный вход

## 📐 Как я проверяю результаты

1. **Самопроверка сборщика** — контрольные суммы до записи файла, падение при расхождении
2. **Независимый верификатор** — отдельный скрипт читает артефакт заново (формулы, итоги, колонки)
3. **Сверка с первоисточником** — банковская выписка «поступления + списания = итог файла»
4. **Журнал проверки** прикладывается к каждому артефакту
